# v1.36.0：魔法地圖與第一批玩法改善

## 使用者確認的規則

- 劇情固定有探索迷霧，不可關閉。其他非搶購模式可在開局前設定，預設關閉；多人跟隨房主。
- 沿實際走廊探索，牆壁會阻擋視線。小地圖和放大地圖都使用同一份個人探索紀錄。
- 拾取魔法地圖後完整顯示當下迷宮，不受秒數限制。所有模式皆在迷宮變形／重建後重新探索，不跨層永久揭露。
- 魔法地圖額外生成，不占道具數量：11 格以下一張，13 格以上兩張。開局和變形均生成；不與食物、原物資、起點、出口、劇情人物重疊。
- 劇情變形不重生其他物資，只補上述地圖。劇情背包原有地圖也採同樣揭露規則。
- 原有金色出口路線仍有 12 秒／劇情背包 18 秒指引（保留職業延時）；路線到時不會重新遮住已揭露地圖。
- 存檔保留個人探索，只有牆面排列完全相同才復原；新布局不能沿用舊迷霧狀態。沒有新增對外傳送探索紀錄。
- 小地圖放大尺寸：桌面 192、一般橫式 160、低高度橫式 132 像素，原尺寸不變。

## 巡查改善：第一批

1. 尋寶、鬼抓人、搶購：真人與電腦不能隔實牆命中或搶奪，接收訊息也檢查距離和牆體。
2. 尋寶／合作奪旗可設定 2～10 分鐘，預設 5 分鐘。到時有人持寶／持旗才延長一次 30 秒，仍未完成即平手。背景計時也收尾；尋寶結果沿既有心跳補送，奪旗沿既有快照同步。
3. 鬼抓人保留最後誰是鬼的勝負規則，另記抓捕次數，每次 50 分、每輪最多 1000 分。總賽事仍先比勝場，再比分數。
4. 搶購可選未結帳商品只計 50%；預設仍按全額，已結帳與蒐集獎勵不折減。

本批未重設原本高級裝備疊加公式。前次巡查提到的跨層人物回應、短事件、章末機關、副本變體、長期挑戰收錄、訂單與合作指路仍屬後續批次，不能視為本版本已完成。

## 原創圖集與效能

使用內建圖片生成製作 `assets/maze-materials-v1.webp`，九款壁面／地板材質合為一張約 398 KiB 圖集，實際遊戲才懶載入。

每個表面從建立起使用固定 256 × 256 貼圖，載入圖片後不改變 GPU 儲存尺寸，避免 WebGL 貼圖更新失敗。重用原牆面、地板、色盤與材質，不新增逐物件光源、模型或繪製批次。下載失敗保留程序材質。

生成提示詞：

> Use case: stylized-concept. Asset type: production texture atlas for an original family-friendly fantasy 3D moving-maze game, applied to real geometry, not a scene illustration. Create one square 3 by 3 atlas of nine EXACT equal square material tiles, touching with no gutters, frames, labels or borders. Reading order top row: pale carved sandstone brick wall with carefully bevelled blocks; pale aged cobblestone floor; pale dense leafy hedge. Middle row: light natural rough stone with thin fractures; pale weathered wood planks with refined grain; pale short grass and moss ground. Bottom row: black volcanic cracks with soft gold-orange molten fissures; pale ice crystals and frosted stone; pale antique library carved wall panels. Orthographic flat material surfaces, edge-to-edge, high craft, subtle hand-painted game art, fine surface microdetail, subdued ambient occlusion and uniform neutral lighting. Most tiles nearly white/neutral gray with restrained color because the game applies biome tint. Each tile must tile seamlessly by itself on all four edges; consistent scale, no perspective, no objects, no plants protruding, no foreground prop, no shadows from external objects, no text, no logos, no watermark. 1536 by 1536 overall composition if available.

實際輸出 1254 × 1254，再壓縮為 WebP；未增加文字或商標。
