# 🌀 3D移動迷宮

目前版本：**v1.18.0**（版本號顯示在遊戲首頁下方與遊戲設定，改版時同步更新 `index.html` 裡的 `GAME_VERSION`）

給國小學生玩的 3D 變形迷宮遊戲，支援平板 / 手機觸控與電腦鍵盤。

手機與平板固定使用橫式：直向時會顯示轉向提示並暫停操作，橫向後才進入角色選擇與遊戲畫面；支援 Screen Orientation API 的瀏覽器會在開始遊戲時嘗試鎖定橫式。

## 獨立專案說明

本專案由公開庫 `CHRIS-CHEN-0503/ziwei-test` 的 `3D迷宮/` 抽離，並把原本位於倉庫根目錄的 `functions/api/scores.js` 一起帶入，因此可直接作為獨立的 Cloudflare Pages 專案部署。

## 玩法

- 選角色（6 種）、選關卡環境（6 種）、選視角（第一人稱 / 第三人稱 / 俯視，遊戲中可隨時切換）。
- 每種玩法可選 **1～10 輪**；每輪是一場完整遊戲，結束後統計每位玩家的累計勝場與總分，最終以「勝場優先、總分次之」排列。
- 真正的可拾取物都有明亮地面光圈與垂直光柱；沒有標記的水果、植物、岩石與貨架陳列都是場景裝飾。
- **三種視角資訊量是公平的**，都看不到牆壁後面：
  - 第一人稱：站在角色眼睛的高度。
  - 第三人稱：像另一個人跟在主角後方的**平視**視角，鏡頭比牆矮；後方有牆時鏡頭會自動拉近，不會穿牆。
  - 俯視：只露出玩家腳邊一圈（半徑約一格半）的圓形視野，其他區域被雲霧遮住；可拉近拉遠。
  - 例外：🦉 貓頭鷹道具可以短暫看到整個迷宮。
- 走到金色傳送門就過關，**越快過關分數越高**。
- **飽足感**會隨時間減少（預設 3 分鐘從 100% 到 0%，後台可調），**歸零就闖關失敗**。
  - 飽足感 ≤ 50%：移動速度 ×0.8（降低五分之一）
  - 飽足感 ≤ 25%：移動速度 ×0.75（降低四分之一）
  - 加速道具是乘在「降速後」的數值上。
- 迷宮每隔一段時間會**變形**：變形時人物不能移動並顯示「迷宮變換中」警告；新迷宮是**以人物所在位置為中心重新生成**，玩家永遠不會被牆壁困住（完美迷宮演算法保證所有格子相通）。
- 變形時**出口也會搬家**：新位置在迷宮外圈的四個角或四條邊線上的任一格（單機保證離玩家有一段距離），記得看小地圖。
- 每次變形會隨機重新出現道具**和食物**。

## 💎 尋寶模式（單機打電腦 / 多人連線）

- 小地圖會標出寶藏 💎 的位置，**撿到寶藏後帶到出口 🚩 才算獲勝**。出口在外圈、寶藏保證離出口至少 1/3 張地圖遠，搶到手還得跑一段路，隨時可能被劫。
- **單機**：標題畫面選「💎 尋寶對戰」，會有電腦對手來搶（13×13 以下 1 個、15×15 以上 2 個）。電腦會自己找寶藏、搶奪、帶去出口。
- **多人**：多人連線選「💎 尋寶」；15×15 以上的大地圖若人數不足，由電腦補位到房間人數上限（最多 4 台電腦）。
- **攻擊與搶奪**：有人拿到寶藏後，沒拿寶藏的人會出現攻擊鍵（電腦按 `X`），每個職業武器不同：
  小勇🗡️小木劍、小花🍳平底鍋、阿丹🥊拳擊手套、莉亞✨魔法棒、鐵蛋🔧大扳手、喵喵🐾貓爪。
  - 打中任何人 → 對方**暈眩 3 秒**（後台可調）。
  - 打中「寶藏持有者」→ 搶走寶藏（同時對方暈眩）。
  - 拿著寶藏的人**不能攻擊**（雙手抱著寶藏）。
- 寶藏被拿走後，持有者位置**每 3 秒**（後台可調）在小地圖上更新一次，大家都追得到。
- 此模式不會肚子餓；迷宮照樣定時變形、出口照樣搬家。

## 🛒 搶購模式（單機打電腦 / 多人連線）

「在大賣場裡搶購」的模式：**沒有任何技能可以用，比的是眼力和跑法**。

- **場景換成大賣場**：走道兩旁不是牆，而是**只有 1.25 單位高、擺滿彩色商品的矮貨架**（一般迷宮牆是 3），所以站著就能**看到遠方的商品和其他玩家**，但走法還是迷宮，一樣要繞。
  - **天花板比其他關卡低（3.2）**，是輕鋼架方格天花板，上面有 9 組雙管日光燈盤和 **4 台會轉的吊扇**。
  - 四周有店牆（擋住外面的天空）、吊掛分區招牌（🥦🍖🥛🍞🧃🧻）、**靠牆的 4 個收銀台**（櫃檯＋輸送帶＋💳＋「收銀 1～4」牌子）、入口推車與特價汽球。
  - 第三人稱鏡頭在賣場會**從貨架上方掠過**（鏡頭 2.35 高、貨架只有 1.25），看得到整個賣場。
- **大家的速度都一樣，而且是平常的 1.2 倍**（5.2 × 1.2 = 6.24）：職業加速在這個模式不算，純比操作。
- 🛒 **每個角色身前都推著一台購物車**（自己、其他玩家、電腦都有）：
  - 一開始是空的，買越多**漸進式地堆得越滿**，最多 8 格（兩層 × 每層 4 格），堆疊用的顏色就是最近買到的那幾樣商品。
  - 格數＝`min(8, 買到的件數, 1 + 金額 ÷ 60)`：第一件就看得到東西，$420 左右堆滿；被搶走商品時車上也會跟著變少，所以遠遠看車子就知道誰買得最多。
  - 面對貨架時**車頭會自動收回來**，不會插進貨架裡。
- 🐢 **車越重跑越慢**（重量用「車上還沒結帳的金額」算，裝滿是多少 $ 可在遊戲設定調，預設 $400）：

  | 車上重量 | 速度倍率 |
  |----------|----------|
  | 未滿 50% | ×1.2 |
  | 50% 以上 | ×1.1 |
  | 75% 以上 | ×1.0 |
  | 裝滿 100% | ×0.9 |

- 💳 **結帳檯**：
  - 場上有 **2 台收銀機**（**雙人局只有 1 台**），兩台之間保證隔了半張地圖以上，**每次迷宮變換都會換位置**。
  - 收銀機有櫃檯、輸送帶、💳、地上的光圈、一根「💳 結帳 N」的招牌和一道**直達天花板的藍色光柱**（走近時會淡出，不會擋畫面），**小地圖上也會標出位置**。
  - 走到旁邊（2.6 單位內）且車上有東西時會出現**結帳鈕**（電腦按 `B`）。按下去**站著等 5 秒**：這段時間不能移動，但**不會被搶**（按鈕會顯示倒數）。
  - 結完帳：車上的錢變成**已結帳**（安全入帳，再也搶不走）、購物車清空、速度恢復 ×1.2。
  - **迷宮變換會中斷結帳**（收銀機也換位置了），車上的東西不會不見。
  - 最後計分＝**已結帳 ＋ 還在車上的**，結算畫面會分別顯示。
  - 電腦對手也會結帳：車上超過 60% 就會自己走去最近的收銀機排隊。
- **商品**（走道上到處都是，撿到就進購物車）：

  | 商品 | 金額 | 出現機率 |
  |------|------|----------|
  | 🍬 糖果 | $10 | 高 |
  | 🍞 麵包 | $20 | 高 |
  | 🥛 牛奶 | $30 | 高 |
  | 🧃 果汁 | $35 | 中 |
  | 🍫 巧克力 | $45 | 中 |
  | 🧀 起司 | $60 | 中 |
  | 🍖 大肉排 | $80 | 低 |
  | 🦞 龍蝦 | $120 | 很低 |

  每件商品頭上會浮出 `$金額` 標籤，小地圖上也看得到。
- **補貨**：商品被搶走後 **6 秒會在別的地方重新上架**（不會補在任何人腳邊，避免白送），所以架上永遠有東西可以搶，整場都不會空。
- **完全沒有技能**：不能攻擊、不能隱身、鐵鍬／風箏／口哨全部收起來，**連職業能力也不計算**。
- 🤏 **搶奪**：從對手身邊（2.4 單位內）經過時按右下角的搶奪鈕（電腦按 `X`），**隨機搶走對方購物車裡的一件商品**。
  - 判定方式跟攻擊鍵一樣：找範圍內最近的人，搶到就把那件商品從對方購物車轉到自己的購物車，兩邊金額同步更新。
  - 有對手在範圍內時按鈕會變成**橘色閃爍**提示；沒人時按下去顯示「💨 搶空了！要靠近對手才搶得到」，對方購物車空的則顯示「🤷 ○○○ 的購物車是空的！」。
  - **搶到的人**看到「🤏 搶到了！🍖 大肉排 $80（從 ○○○ 的購物車）」，**被搶的人**看到「😱 被 ○○○ 搶走了 🍖 大肉排 $80！」。
  - 冷卻 1.5 秒。**電腦也會搶**：開場 8 秒的緩衝後，每台電腦每 8 秒最多搶一次。
  - **正在結帳的人搶不到**（會顯示「○○○ 正在結帳，搶不到！」）。
- **道具只有兩種**：⚡ 加速藥水、😜 調皮鬼（把所有人隨機傳送，包含自己）。
- 沒有飽足感、沒有終點傳送門；**時間到誰的購物車金額最多誰就贏**（預設一場 2.5 分鐘，遊戲設定可調 1～10 分鐘）。
- HUD 隨時顯示 `🛒 $金額 第N名｜領先 $X｜剩 Z 件`，結算畫面依金額排出 🥇🥈🥉。
- **單機**：標題畫面「選擇玩法」選「🛒 搶購模式」，跟 2 個電腦對手比。電腦會走去最近的商品，撿到後要花 1.4 秒裝進購物車，而且跑得比真人玩家慢一點（真人 6.24、電腦 5.16），認真跑就贏得了。
- **多人**：多人連線選「🛒 搶購」，2～5 人一起搶；商品位置與補貨由房主決定後同步廣播，每台裝置看到的貨架完全一樣。

## 👥 多人連線（2～5 人）

- 標題畫面按「👥 多人連線」。房主**先選人數上限（2～5 人）**與模式並建立房間（得到 4 位數房號），朋友輸入房號加入，房主按開始（2 人到齊就能開始，不必等滿）。房間滿了之後想加入的人會看到「房間人數已經滿了」。
- **出發點自動安排**：依實際迷宮路徑計算，2～5 人都會被放在**彼此距離最遠**的位置；比賽與尋寶模式還會保證每個出發點到出口的路程都差不多遠（公平），鬼抓人則散布全圖。
- **多人模式視角可自由切換**（因為三種視角都設計成看不到牆後，資訊公平）。
- 🛒 **搶購大作戰**：大賣場裡比誰的購物車金額多（詳見上一節）。
- 🏁 **比賽搶終點**：大家從分散的出發點出發，終點在迷宮正中間（距離公平），最快到的贏。有飽足感機制，餓昏＝出局。
- 👹 **鬼抓人**：隨機一人當鬼（腳下紅圈、跑速為一般玩家 1.15 倍）。**鬼要用「攻擊」打中別人才算抓到，觸碰沒有用**。2 分半後還是鬼的人輸。此模式沒有終點。
  - 🔄 **換鬼流程**：被抓到的人變成鬼，會**定住 3 秒**（戴上面具），同時全場大字公告並播放語音「換 ○○○ 當鬼，快跑啊！」——**男生角色抓到人放男聲、女生角色抓到人放女聲**（裝置沒有男女中文語音時用音調高低模擬），大家趁機逃跑。
  - ⚡ **鬼的攻擊冷卻只要 0.75 秒**（一般玩家 1.5 秒），追到就連打。
  - 👃 **鬼的敏銳鼻子**：有人在附近（預設 3 格，遊戲設定可調 1～8 格）時，鬼會聞到味道——地上沿著迷宮通道浮現 👣 **腳印路標**指引方向（越遠越淡），畫面上方顯示方向箭頭與距離幾格，第一次聞到還有吸鼻子音效。目標跑出範圍就消失；**隱身中的人氣味被遮住，聞不到**（小花的隱身仍然有效）。
  **單機也能玩**：標題畫面「選擇玩法」選「👹 鬼抓人」，跟兩個電腦對手玩——電腦當鬼會追最近的人，不是鬼時會往離鬼最遠的角落逃。
  - ⚔️ **互相攻擊**：所有人隨時可用攻擊鍵（電腦按 `X`）互打，武器同尋寶模式。
  - 🍗 **飽足感照樣會減少**（速度懲罰跟經典模式一樣：≤50% ×0.8、≤25% ×0.75），但**餓到 0% 不會失敗，只是一直跑很慢**，撿食物就能回復。
  - ❤️ **體力**：被打中扣 1 格，歸零＝暈眩（暈完體力恢復）。一般人 1 格且不自動回復；**鬼每 15 秒自動回 1 格**。
  - 👺 **鬼面具與鬼能力**：當上鬼會隨機獲得一種職業能力並戴上對應面具（大家都看得到）：
    👺疾風（速度再 ×1.12）、🎭隱身、😈體力+1、🎃道具時間×1.5、💀鐵鍬工具箱（變鬼當下立刻拿到一把）、👁️雷達。
    抽到跟自己職業相同的能力會**疊加**（例：阿丹當鬼抽到體力＝3 格；小勇疊疾風更快；喵喵疊雷達變 2.5 秒一次；小花疊隱身變 10 秒；工程師疊鐵鍬上限變 2 把）。
  - 🔁 **鬼抓人的職業能力**（取代原本用不到的能力）：阿丹＝體力 2 格、小花＝隱身 5 秒（技能鍵／`C`，冷卻 30 秒；隱身可移動、位置照常同步、仍會被打中）、喵喵＝每 5 秒在小地圖看到所有人位置。
- 兩種模式中迷宮照樣定時變形（所有人的迷宮完全同步），道具、食物大家搶（先撿先贏）。
- 連線走 MQTT over WebSocket，預設用公用伺服器 `wss://broker.emqx.io:8084/mqtt`。若學校網路擋住或想要更穩，可在後台換成其他公用 broker（如 `wss://broker.hivemq.com:8884/mqtt`）或自己架的 aedes/mosquitto。只在網路上傳玩家名字和位置，不傳其他資料。

## 操作

- **平板 / 手機**：左半邊拖曳＝虛擬搖桿移動；右半邊拖曳＝轉視角；**動作鈕（攻擊／搶奪／結帳／鐵鍬／風箏／口哨／技能／視角／音樂／拉近拉遠）可以在拖著搖桿移動的同時按，不必停下來**——這些按鈕綁的是 `touchstart` 而不是 `click`，因為多指同時觸控時瀏覽器不一定會對第二根手指送出 click 事件；點小地圖放大成全螢幕、小地圖左上角 ⤢ 鈕切換 1.2 倍大小；俯視時雙指開合（或＋－按鈕）拉近拉遠。
- **電腦**（按鍵用實體位置偵測，**開著注音/倉頡等中文輸入法也能玩**）：
  - `WASD` / 方向鍵：移動
  - 滑鼠按住畫面右半邊拖曳，或 `Q` / `E`：轉視角
  - `空白鍵`：用鐵鍬敲牆
  - `F`：用風箏飛牆
  - `X`：攻擊（尋寶／鬼抓人）／🤏 搶奪商品（搶購）
  - `B`：💳 結帳（搶購）
  - `C`：隱身技能（鬼抓人）
  - `G`：集合口哨（鬼抓人／尋寶）
  - `M`：開／關大地圖
  - `V`：切換視角
  - 俯視時滾輪或 `+` / `-`：拉近拉遠

## 遊戲設定（標題畫面 ⚙️，原「後台設定」）

- 迷宮變形間隔（0.5 ～ 10 分鐘，預設 3 分鐘）
- 每次出現的道具數量（3 ～ 12，預設 6）
- 每次出現的食物數量（2 ～ 10，預設 4）
- 飽足感可以撐幾分鐘（1 ～ 10，預設 3，歸零＝闖關失敗）
- 尋寶模式：被攻擊暈眩幾秒（1 ～ 10，預設 3）

- 鬼抓人：鬼的嗅覺範圍幾格（1 ～ 8，預設 3）
- 搶購模式：架上商品數量（6 ～ 60，預設 16）

- 搶購模式：購物車裝滿（100% 重量）是多少 $（100 ～ 2000，預設 400）
- 開放的視角（勾選第一人稱／第三人稱／俯視，單機與多人都適用）
- 多人連線伺服器網址（MQTT over WebSocket）
- 迷宮大小（11 / 13 / 15 / 特大 19 / 超大 25）

## 🏆 雲端勇者歷史（讓所有玩家互相看到紀錄）

預設分數只存在各自裝置的 localStorage。想共用勇者歷史有兩種免費做法：

### 方法一（推薦）：部署到 Cloudflare Pages，內建分數 API 直接生效

這個 repo 已附好 `functions/api/scores.js`（Cloudflare Pages Function），**不需要另外寫任何 API**：

1. 到 [Cloudflare Pages](https://pages.cloudflare.com) → Create a project → 連接這個 GitHub repo。
   Build 設定全部留空（純靜態網站），Deploy。
2. Cloudflare dashboard → Workers & Pages → KV → Create namespace（名字隨意，例如 `maze-scores`）。
3. 回到 Pages 專案 → Settings → Bindings → Add → KV namespace，
   **Variable name 填 `SCORES`**，選剛剛建立的 namespace，Save 後重新部署一次。
4. 完成！遊戲會自動偵測同網域的 `/api/scores`，勇者歷史立刻變成所有玩家共享，遊戲設定的 API 網址欄位保持空白即可。

（沒綁 KV 也能正常部署，只是勇者歷史維持各裝置本機模式。多人連線與 Cloudflare 無關，走的是 MQTT 伺服器。）

### 方法二：放在 GitHub Pages 等其他靜態空間，用 Google Apps Script

1. 到 [script.google.com](https://script.google.com) 建立新專案，貼上：

```javascript
const SHEET_ID = '你的Google試算表ID'; // 建一張空白試算表，把網址中的 ID 貼過來

function doGet() {
  const sheet = SpreadsheetApp.openById(SHEET_ID).getSheets()[0];
  const rows = sheet.getDataRange().getValues();
  const records = rows.map(r => ({
    name: String(r[0]), char: String(r[1]), level: String(r[2]),
    timeSec: Number(r[3]), score: Number(r[4]), date: String(r[5]),
  }));
  return ContentService.createTextOutput(JSON.stringify(records))
    .setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  const sheet = SpreadsheetApp.openById(SHEET_ID).getSheets()[0];
  const r = JSON.parse(e.postData.contents);
  sheet.appendRow([
    String(r.name).slice(0, 20), String(r.char).slice(0, 4), String(r.level).slice(0, 20),
    Number(r.timeSec) || 0, Number(r.score) || 0, String(r.date).slice(0, 10),
  ]);
  return ContentService.createTextOutput('ok');
}
```

2. 「部署 → 新增部署 → 網頁應用程式」，執行身分選**我**，存取權選**所有人**。
3. 把部署後的網址（`https://script.google.com/macros/s/.../exec`）貼到遊戲的「⚙️ 遊戲設定 → 勇者歷史 API 網址」。

之後每次過關會自動 POST 上傳紀錄，勇者歷史會合併顯示雲端＋本機紀錄。

## 技術說明

- Three.js（`lib/three.min.js`，本地載入不依賴 CDN）。
- 牆壁用 InstancedMesh 一次繪製；每個關卡有自己的程序化 Canvas 材質（城堡石磚、草原樹籬、岩石、森林木板、草地、火山岩＋發光岩漿裂縫），不依賴外部圖片，行動裝置效能友善。
- 音樂與音效全部用 WebAudio 即時合成，六個關卡六種曲風：城堡＝鐘樓圓舞曲、草原＝大調快板、山洞＝回音慢板＋水滴聲、森林＝木笛五聲音階＋鳥鳴、迷霧＝小調幽靈慢板、火山＝小調冒險快板。要換自己的音樂改 `AudioEng.SONGS` / `startMusic` 即可。
- 迷宮：遞迴回溯完美迷宮 + 8% 打通率做環路；變形時從玩家所在格子重新生長。
- 🛒 搶購模式重用同一套迷宮與多人架構：只是把牆高降成 1.25、換上大賣場主題（貨架程序化貼圖＋店牆＋輕鋼架天花板＋吊扇＋收銀台）、每個角色掛上一台以 Box 組出來的購物車（`buildCart` / `fillCart`，堆疊格共用同一組材質色）、關掉技能與飽足感，商品的位置與補貨由房主用 `restock` 訊息廣播，所以每台裝置的貨架完全一致。搶奪走 `rob` 訊息（帶著被搶的品項編號），每台裝置各自結算成同一份帳。俯視時天花板燈、吊扇與吊掛招牌會自動隱藏，不會擋住迷宮。
