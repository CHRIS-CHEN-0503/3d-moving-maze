# 高塔原創配樂

製作日期：2026-09-07。十個環境各一首，另有一首遭遇戰曲，共十一首。

所有旋律、和弦進行、節奏及音色均由本專案的 `tools/生成高塔配樂.mjs` 自行編排和合成，未使用外部歌曲、商業取樣庫、第三方音效或生成式音訊服務；沒有需要另外取得授權的外部音樂素材。玻璃、木質、氣息、鐘聲等名稱描述合成音色，不代表使用真實樂器取樣。

## 製作方式

使用 Node 離線產生 32,000 Hz、雙聲道、16-bit PCM 母帶，再以 macOS 內建 `afconvert` 壓縮為 AAC／M4A。編碼目標為每秒 64,000 位元；系統編碼器實際輸出大小依內容調整。母帶只寫入本次建立的暫存目錄，完成或失敗時均清除，網站僅提供壓縮音檔。

每首有三音和弦底層、低音、獨立旋律、琶音及輕打擊。一般環境八小節，遭遇戰十二小節；不同環境使用不同速度、調式、旋律動機、和弦進行與主奏音色。音色採基音及少量低次諧波，不使用尖銳方波。音符有起音與釋放包絡，低頻打擊有平滑起音；主輸出移除直流偏移並保留音量餘裕。

延音及左右聲道反射會環接至同一循環的開頭，不在結尾製造靜音。AAC 音檔重新解碼後驗證時長、波形峰值、平均能量與頭尾相鄰取樣差；播放管理仍應使用原有淡入／淡出，以避免切換場景或遭遇戰時突變。

## 重製及驗證

需求：現有 Node 與 macOS `/usr/bin/afconvert`，不需安裝依賴。

```sh
node tools/生成高塔配樂.mjs
node tools/生成高塔配樂.mjs --check
```

第一個命令重製十一首音檔並驗證；第二個只解碼檢查現有音檔，輸出每首秒數、大小、峰值、平均能量、接縫差及摘要值。指令應透過專案的有限執行時間保護器執行。

本機既有 `ffmpeg` 因缺少 `libass.9.dylib` 無法啟動，因此沒有使用或修改該工具，也沒有安裝套件。受限沙箱中的 `afconvert` 可能列不出 AAC 編碼器；本次經核准使用系統音訊編碼能力後完成壓縮及解碼。這不改動系統設定。
