# 專用語音與清楚播報

> 這是 v1.33 的歷史記錄。正常語速、男女角色配聲與發音重錄請以 [v1.34 更新](語音配角與圖片陷阱-v1.34.md) 為準。

## 遊戲中的行為

- 大拍賣固定播放一個完整句音檔：「大拍賣！限時 XX 秒，快來搶購！」。依地圖選 15、20、25 秒，不再拼接商品名稱，也不加「只有六件」。
- 首頁六個選項、人物職業、環境及單人／多人玩法、視角選擇只念名稱。
- 一般與劇情模式的取得／使用道具維持「獲得 餅乾」「使用 鐵鍬」等短句。背包、交易及裝備只讀重點，不念全部數值。
- 單人過關讀「恭喜過關！」，失敗及多人結算讀「遊戲結束」，不自動長篇朗讀排行榜。
- 主線每頁、結局、六種裂隙逸聞、舊副本信件及旅途回聲的固定文字都有專用音檔索引；日誌仍可完整重聽。
- 玩家姓名、隨機數字、未收錄的新文字及音檔載入失敗，保留裝置朗讀。設定裡的聲音選擇只影響這些動態／備援文字，固定音檔使用同一位合成女聲。
- 所有朗讀共用一條佇列；叫賣優先取代舊提示，道具提示不打斷叫賣。換頁、停止、關閉語音或頁面進入背景，都會取消舊朗讀。
- 音檔共用同一個播放器，保留使用者第一次點擊啟動的播放權限，避免每段新建播放器。此做法依循 [WebKit 的逐元素自動播放政策](https://webkit.org/blog/7734/auto-play-policy-changes-for-macos/)，但仍須實機確認各版本手機的音量及播放設定。
- 只在遇到相應內容時下載該段聲音，不預先下載全套音檔，不在手機執行生成模型。播放期間降低背景音樂、道具循環聲及一般音效，結束後恢復音量；攻擊等提示音仍保留。載入八秒仍無法播放則嘗試裝置朗讀。
- 「遊戲設定」新增「試聽大拍賣」；語音開關與音樂開關獨立。

## 維護與生成

`tools/build-voice-catalog.mjs` 從遊戲已有文字建立穩定內容雜湊索引。修改劇情文案後先重建索引，再生成缺少的音檔。程式不把玩家輸入傳給生成服務。

Apple Silicon 開發環境使用 `tools/generate-voice-mlx.py`，依 [MLX Audio 官方使用方式](https://github.com/Blaizzy/mlx-audio/blob/main/mlx_audio/tts/models/qwen3_tts/README.md) 以 Qwen3 CustomVoice 1.7B／Serena 內建合成聲線生成，沒有複製真人聲音。依賴裝在專案外的獨立環境，不上傳模型或開發服務。

合成時先統一中文異體字寫法，再輸入模型，改善「搶購」等文字的發音；遊戲畫面、索引及故事正文仍是原本的繁體中文。音檔做輕微降速及響度統一，無迴音效果。`tools/check-voice-audio.py` 可對選定前綴做獨立辨識與格式檢查，報告留在開發記錄，不加入玩家下載資產。

長篇生成保留額外長度餘裕；若輸出碰到上限，程式會停止並拒絕儲存，避免把截斷的句子當成完成品。每段先寫暫存音檔，成功後才替換正式檔案。`--retry-ids` 可指定需要重做的既有音檔，其餘完成內容不需重做。

```sh
node tools/build-voice-catalog.mjs
# 在已安裝 mlx-audio==0.5.5、soundfile、opencc-python-reimplemented 與 ffmpeg 的開發環境執行：
python tools/generate-voice-mlx.py --prefix=generated. --batch=4
python tools/generate-voice-mlx.py --prefix=shop.sale.clear. --force
```

亦保留 `tools/generate-voice-pack.mjs` 作為原有本機 Voicebox 生成路徑。它僅接受 localhost，不需要付費語音服務金鑰。

生成後必須執行 `npm run check`：檢查固定文字覆蓋、索引對應、檔案存在與尺寸、序列播放、取消、靜音、動態備援及大拍賣觸發。再執行 `node tools/check-voice-assets.mjs` 完整解碼所有索引音檔，檢查格式、時長、大小及無聲問題。音檔另做辨識抽查；自動辨識不能取代使用者實際試聽。
