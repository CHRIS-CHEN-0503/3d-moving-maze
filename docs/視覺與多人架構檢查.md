## v1.18.0 資產盤點

- `index.html` 沒有載入任何外部圖片 URL；實際影像皆由 `assets/` 本地載入。
- 字型使用作業系統字型堆疊，沒有 Google Fonts，也沒有 Font Awesome、Material Icons 或其他第三方 icon 套件。Three.js 為本地程式庫，不是外部 UI 圖示來源。
- 主要可點擊 UI 圖示已專屬化；玩法說明、狀態提示與道具名稱內的 Unicode 仍當作文字語意標記保留。
- 部分 3D 場景與道具仍由 `makeEmojiSprite()` 將 Unicode 繪成 Canvas sprite，以保留現有辨識性與效能；本版不假稱這些 3D 語意 sprite 已全部替換。若要完全專屬化，應另案製作完整的道具／食物／場景 sprite 圖集並做逐項辨識測試。

## 後續可做，但本次刻意不動

## Cloudflare 與多人模式

- 現行多人是瀏覽器直接以 MQTT over WebSocket 連到 `wss://broker.emqx.io:8084/mqtt`；Cloudflare Pages 只提供靜態檔案，因此部署後仍可運作，不必為相容性改程式。
- 目前的 4 位房號、QoS 0、公用 broker、無鑑權、無自動重連與無房主轉移，只適合測試或小範圍遊玩。
- 若要正式公開，建議另案改成 Cloudflare Worker + Durable Object WebSocket：每個房間一個 Durable Object，加入不可猜的房間權杖、伺服器驗證、狀態快照、斷線恢復與房間清理。
- `functions/api/scores.js` 只處理分數牆，與多人連線無關；部署時要為新的 Pages 專案綁定自己的 `SCORES` KV。
