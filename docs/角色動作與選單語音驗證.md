# v1.42.4 角色動作、選單語音與手機圖示

## 動作設計

| 武器 | 動作一 | 動作二 |
|---|---|---|
| 長劍 | 斜向斬擊 | 舉劍下斬 |
| 雙手劍 | 雙手劈斬 | 橫向重斬 |
| 鐵鎚 | 舉鎚敲擊 | 側向錘擊 |
| 重錘 | 蓄勢重砸 | 雙手橫掃 |
| 平底鍋 | 橫向拍擊 | 向前上挑 |
| 雙短刃 | 右手接左手 | 左手接右手 |
| 法杖 | 前指施法 | 提杖聚能 |
| 法書 | 單手引導 | 雙手托書 |

42 種主動技能依性質共用斬擊、旋斬、重擊、突刺、施法、治療、護盾、鼓舞、料理、鍛造、架設、斥候動作。既有需準備的技能先做持續準備姿勢，再釋放；取消、換層與倒地清除姿勢。普通攻擊逐次輪替，技能不消耗普通攻擊的輪替順序。

此模組只控制模型關節，沿用既有畫面更新，不新增計時器、光源、貼圖或人物模型。傷害、命中、冷卻、材料與準備秒數不變。

## 語音原則

營地、工坊、背包、隊伍與裝備、圖鑑、技能排序、補給設定、成長、照明及行商操作頁安靜開啟。點選導覽功能只唸功能名稱。成功料理、修復、獲得或使用道具的原有回饋保留。

故事正文、日誌、任務、確認提示與手動重聽不受這項靜音規則影響；手動重聽讀目前頁面，不是上一頁故事。

## 本機驗證

- `npm run check`：規則、動作、語音策略、圖示尺寸、現有遊戲測試。
- `tools/tower-motion-browser-qa.mjs`：844 × 390 手機橫向尺寸，七次選單開啟不自動朗讀、點功能只唸名稱、手動重聽與故事保留、八類武器雙動作、圖示資產連結。診斷畫面使用遊戲原本的人物製作函式。
- `tools/tower-feedback-browser-qa.mjs`：命中、技能準備與釋放、照明捷徑及光影音效回歸。
- 圖片與報告保存在不納入版本控制的 `.agent-run/motion-qa/` 及 `.agent-run/feedback-qa/`。

本紀錄不表示已推送或部署，也不把電腦瀏覽器的手機尺寸測試當作實體手機測試。
