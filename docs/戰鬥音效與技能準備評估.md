# 戰鬥回饋與準備時間評估

## 本次已實作（本機 v1.42.3，未部署）

- 普通攻擊、隊友攻擊、近戰技能、飛彈及延遲範圍技能，僅在規則確認命中後產生接觸光影與命中音效。物理武器為短促斬痕／撞擊火花；法杖、法書為法術迸光。
- 42 個主動技能依動作分類播放原創合成音效，涵蓋斬擊、金屬重擊、法術、冰霜、治療、護盾、偵察、煙幕、烹飪、鍛造及裝置。
- 背包與快捷道具、隊友自動用藥、穿脫裝備、營地料理／修理／鍛造／拆解、刻印、點燃火把及機關操作，成功執行後播放對應音效。
- 十招依確認後的秒數準備，完成才套用效果、扣材料與開始冷卻；未改傷害、材料數量或冷卻長度。拆解陷阱保留原本開始即消耗冷卻與受傷／移動中斷規則，作業時間各級加 0.5 秒。
- 音效使用共用靜音設定，波形快取、最多四個聲源，同類命中音至少間隔 65 毫秒。特效最多十二組，不增加即時光源、陰影或全畫面閃白；遵守已設定的視野遮蔽及減少動態效果偏好。

## 已確認並實作：所有建議準備時間增加 0.5 秒

主角與隊友使用同一套準備流程。拆解陷阱第 1～6 級改為 3.5／3.1／2.7／2.3／1.9／1.5 秒。

| 技能 | 最終準備時間 | 原因 |
| --- | --- | --- |
| 星隕術 | 1.5 秒詠唱 | 範圍攻擊，先顯示落點。 |
| 星環轟擊 | 1.9 秒詠唱 | 主角高階大招，準備較長。 |
| 破陣決斬 | 1.3 秒蓄力 | 強力近戰斬擊。 |

普通攻擊、飛彈、草藥療癒、護身結界、驅散震波、煙幕及快捷藥水維持即時，不新增準備時間。

倒數顯示在技能按鈕，不占畫面中央；準備中的人物不能同時普攻或施放其他技能。保持原本移動速度，一般受傷不中斷（拆解例外）。完成時重新驗證人物、目標、材料及武器，失敗不扣材料、不開始冷卻。暫停凍結進度；換層、變形、死亡、离隊與切換受控角色取消其準備。取消不扣材料；準備狀態不存入存檔。冷卻與材料數量不變。

尚未採用：準備時減速、閃避取消、取消後額外防連點冷卻。這些不屬於此次延長秒數的必要變動。
