# 高塔遠征：第一階段（v1.37.0）

本版是一般版遊戲內的「劇情模式」擴充，不是春酒版。取材於迷宮冒險中的職業分工與食材生態概念，角色姓名、美術、規則與既有高塔主線皆為本遊戲原創；不使用漫畫人物、圖片或台詞。

## 已實作

- 主角先選外觀與名字，再選劍士、術士、鎖匠、廚師、療癒師、裝備師。外觀不再疊加一般版的原職業能力。
- 主角加最多三位旅人，總計四人。**劍士就是護衛**。同伴強度 1～5；沒有另一個額外的護衛名額。同職業同伴不能重複招募，主角可與同職業同伴同行。
- 招募旅人出現在隨機安全格，不固定起點；99、97、95、93、91、89 層依序介紹六種職業，其餘樓層約 45% 機會出現。價格為 `8 + 強度 × 4` 銅幣。離隊前確認，費用不退，同一旅人不能在原地反覆招募。
- 劍士近身攔截並承傷、術士遠距支援、鎖匠降低陷阱傷害、廚師一次做兩份料理、療癒師消耗香草救援、裝備師減少修理費。主角也各有一個技能，畫面直接顯示，不放進收合選單。
- 怪物有生命值。主角與作戰同伴能討伐怪物；武器命中扣一耐久，主角命中可短暫擊暈，之後有四秒抗暈期。武器用壞仍可徒手攻擊，商人原本固定販售的裝備種類保持不變。
- 同伴倒下不是永久死亡；分享料理或回起點／行商營地消耗乾糧休息即可恢復。再次招募不會重置現有同伴的生命。
- 新增蒲傘菇（孢子緩速）、岩殼蟹（正面硬殼）、蜜囊蛾（提醒附近怪物）、蔓嘴花（固定砲台，種子可由牆壁擋住）。與原五種怪物共九種。仍保留前段較安全、中後段較危險的分布，當層最多六隻。
- 部分原有劇情物資改成甜根莖、月傘菇、香草、花蜜；不增加原物資總數。討伐取得蟹肉、硬殼等，既有魔法地圖仍額外生成、不占設定數量。採集物與已擊敗怪物不因變形或讀檔重生。
- 八道料理：根莖菇菇燉鍋、香草暖湯、蜜烤菇串、香煎蟹肉、蜜根熱湯、旅人飯盒、發光香草沙拉、團聚大餐。烹飪限營地／行商旁且無近距離敵人，料理可隨時在背包享用。增益最多兩種、持續三層，重複食用刷新期限而非疊加數值。
- 第 90 層「甦醒石陣」：先避開石陣預警與升起的石柱，在平息期解除兩座封印。
- 第 80 層「吞光庭園」：在安全期轉動兩座光鏡，將光對準附近金色根芽，避開甦醒的藤蔓。兩處完成才解鎖出口；獎勵限一次。仍須完成原本主線印記。

## 保留與後續範圍

全部 99 層原主線、每十層環境、原副本仍可玩；新職業、隊伍、戰鬥與料理可帶到後續樓層。本次先完成 **90、80 層**專屬迷宮挑戰；**70、60、50、40、30、20、10、1 層的不同章末魔王機關尚未加入**，不將它們算作已完成。

整體迷宮變形秒數仍為 `150 - (99 - 目前樓層)`，沒有改成魔王機關的 14 秒局部攻擊循環。機關循環不是整座迷宮重新生成。

保留現有裂隙副本的探索玩法；副本內不生成隊伍戰鬥與招募營地，原層怪物生命與魔王循環暫停，離開副本後恢復。

## 存檔與驗證

使用既有 `maze3d_tower_v1`，在版本 2 旅程內加入經過驗證的可選 `party.version = 1`。未升級舊存檔仍可驗證；續玩選職業後才一次性轉換，保留已付費護衛成為劍士，並先保存 `maze3d_tower_v1_before_party` 升級前備份。備份寫入失敗就不進行升級。**升級後不支援用舊版程式回寫新存檔**，舊版驗證器可能丟掉新增欄位。版本回退前應另外備份目前瀏覽器存檔。

新模組只使用既有更新迴圈、低面數原創幾何、原創向量圖與現有語音朗讀；不加即時燈光、後製或額外圖片下載。新怪物模型各少於 30 個網格、5,000 三角形。尚不能以桌面測試保證每一款手機都有相同幀率。

驗證：`npm run check`；本機整合驗證使用 `tools/run-tower-party-qa.sh`，開啟隔離的測試瀏覽器，將測試介面注入本機回應（正式檔案沒有捷徑），輸出 `.agent-run/party-qa/`。可用 `PLAYWRIGHT_MODULE`、`CHROME_PATH`、`PROCESS_GUARD_DIR` 調整本機相依路徑。測試結束自動停止 8795 連接埠預覽。
