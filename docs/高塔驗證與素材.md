## 驗證方式

`npm run check` 包含既有介面／語法／結構檢查，以及核心規則、引擎資源生命週期、劇情流程、音樂切換的自動測試。專案不是 TypeScript，無獨立型別檢查器；沒有 ESLint 配置，沿用現有靜態驗證器及 JavaScript 語法檢查。

本機實際瀏覽器測試已覆蓋首頁 → 選職業及命名 → 第 99 層開場、原版 W 移動且未穿牆，以及十個章首的建場與出口通路。每區都存在可到達出口的迷宮路徑。

十區逐次載入的實測繪製負載約 159–245 次繪製、10,356–20,570 個三角形（場景會隨生成種子而不同）。這是桌面瀏覽器的渲染負載，不是實體手機幀率保證。手機觸控裝置的像素倍率上限為 1.35；非觸控桌面上限 1.75。每層最多六隻怪物，距離過遠不尋路，沒有每隻怪物專屬光源。

## 已修正的整合問題

- 開場／結局資料結構與顯示狀態對齊；第 1 層完成後只領一次獎勵。
- 重開死亡存檔仍恢復原職業與姓名。
- 對話暫停主迴圈與倒數，關閉時保留原工具冷卻與效果時間。
- 原版道具、食物與劇情補給都有當層拾取紀錄；商人不與道具共用位置。
- 換層取消舊變形與預警；釋放私有模型／材質／貼圖、粒子及武器，保留共用圖集。
- 高塔亮度、牆色與霧距不再被原關卡視角或變形覆寫。
- 存檔失敗會提示，不能誤稱已保存。
- 667 × 375 選關頁可以手指捲至開始鍵，劇情對話提供頂部返回鍵；一般模式完全隱藏劇情狀態列。

配樂已實測 `echo.m4a` 環境曲與 `combat.m4a` 遭遇戰曲實際載入，音訊環境為 running、環境混音峰值約 0.134；按原音樂開關後音樂訊號為 0。音樂管理測試包含環境／戰鬥切換、交叉淡化、快取限制與過期載入取消。

## 存檔邊界

進度只保存在目前瀏覽器，繼續時回到該層入口，已取得物資不會重複出現。怪物重新出現，但同一隻已領過的銅幣獎勵不會重複發放。不跨裝置同步，不接入一般版多人排行榜。
