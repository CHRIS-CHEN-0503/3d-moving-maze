# 隊伍職業與作業效果

初始每位人物是隨機三個主動、兩個被動；主角可升至十級並取得四個額外技能（詳見 [成長規則](主角成長與自動戰鬥.md)）。有該職業不代表擁有全部技能。主動要施放，被動要實際抽到；倒下的隊友不提供隊伍效果。

| 職業 | 隊伍或作業幫助 | 限制 |
| --- | --- | --- |
| 劍士 | 耐力被動讓全隊飽食消耗減少 15／20／25／30／35%；護衛本能可攔截近身怪物。 | 各被動需持有；守護架勢等主動須施放。 |
| 術士 | 日光術照明 10 分鐘；魔力延續延長本人的一般計時道具，奧能調息縮短技能冷卻。 | 需持有相應技能；日光術與火把不因延續而延時。 |
| 斥候 | 避險本能令一般陷阱傷害減少 5／10／15／20／25%；可探路、拆除陷阱與掩護。 | 被動要持有；拆陷阱需靠近，受傷或移動會中斷。 |
| 廚師 | 一料雙份有 20／35／50／70／100% 機率多做一份；美食品鑑令食物恢復的飽食度增加 10／20／30／40／50%。 | 不是只要有廚師就必定兩份，需抽到一料雙份，五級才必定兩份；消耗配方材料。 |
| 療癒師 | 治療、解除異常、扶起倒地隊員；自動救援可在危險時代為施放。 | 一般自動策略可使用已擁有的治療招式；自動救援被動另有開關。耗材技能需允許使用材料，且材料／冷卻允許。 |
| 鍛匠 | 節省工料被動使工坊鍛造與營地費用減少 10／20／30／40／50%；應急修補、加固與磨礪。隊中有能行動的鍛匠可重建零耐久裝備。 | 折扣與主動需持有；重建在安全營地／商人旁，消耗金額與零件，金額採正常缺損修理的 1.5 倍。 |

各職業也可處理對應的探索作業：劍士石門、術士符文、斥候暗門、廚師食材箱、療癒師淨泉、鍛匠機械。依遭遇提供的職業選項處理，不是每層一定有固定作業。

同種隊伍被動不無限疊加，依規則取有效強度。切換帶隊者不會重抽技能、複製裝備或重置冷卻。
