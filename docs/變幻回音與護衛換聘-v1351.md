# v1.35.1 變幻回音與護衛換聘

## 聲音

迷宮開始移牆時朗讀「迷宮正在變幻。新的道路，即將出現。」一般、多人、高塔及副本共用同一變形入口。保留石牆震動；完成通知只顯示文字，不排入第二段女聲。語音與音樂開關仍各自生效。

沿用已確認入口音檔的 `uncle_fu` 聲線、相同導演指示、正常速度；沒有改寫入口原音檔。使用本機 Qwen3-TTS CustomVoice 6bit 生成，不使用真人聲音樣本，不上傳玩家資料。生成定義在 `tools/build-role-voices.mjs` 的 `maze.shift.deep`。

乾聲生成後，以 FFmpeg `lowpass=f=6500,aecho=0.85:0.85:170|370|610:0.26|0.17|0.10,loudnorm=I=-16:TP=-1.5:LRA=9` 製作三層遞減回音，保留清晰主聲；24kHz、單聲道、80kbps。只在播放時載入壓縮音檔，手機不執行生成模型或即時回音計算。重新生成時須先輸出至暫存資料夾，再套上述濾鏡，不可將乾聲直接覆蓋成品。

## 換聘規則

- 靠近未聘過的新戰士，原報價頁提供「解聘並改聘…」。
- 第二頁確認新舊戰力、新聘費用、無退費與不可聘回；交戰中另警告怪物恢復行動。
- 取消不扣款、不改護衛。確認再次檢查距離、視線、樓層、契約及版本。
- 新聘費用全數足夠才執行原子交易，保存成功後才移除舊模型及啟用新模型。
- 無資源或保存失敗時，原契約、模型、牽制狀態皆保留；保存成功才解除舊怪物牽制，不判為擊殺、不給擊殺獎勵。
- 已履行／已解聘的契約保留於歷史，防止重複領取戰力。既有存檔格式不變。
